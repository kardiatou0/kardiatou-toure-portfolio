# Portfolio de Kardiatou Touré

Site professionnel statique en français : cloud, DevOps et DevSecOps.

## Contenu

- Profil professionnel et quatre résultats clés.
- Expérience : missions EDF, Oken Consulting et GSIE Technology.
- Études de cas : pipeline DevSecOps, accès QR, automatisation cloud et projet académique K3s.
- Expertise : DevSecOps, cloud et IaC, systèmes et réseaux, cybersécurité, observabilité, automatisation.
- Contact professionnel et CV PDF sélectionné par Kardiatou.

Les études de cas professionnelles sont des synthèses. Ce dépôt ne contient ni code interne d'entreprise, ni secrets, ni rapports de stage.

## Prévisualisation

Ouvrir `index.html` dans un navigateur ou servir ce dossier avec un serveur HTTP local.

## Publication GitHub Pages

Nom du dépôt : `kardiatou-toure-portfolio`.
Dans Settings > Pages, sélectionner Deploy from a branch, puis `main` et `/ (root)`.

## Modifier le site

Le contenu est dans `index.html`, `experience.html`, `projects.html`, `expertise.html` et `contact.html`. Le style est dans `design.css`, le CV dans `CV_Kardiatou_TOURE.pdf`.
Le site n'utilise aucun suivi, formulaire distant ni dépendance externe.
